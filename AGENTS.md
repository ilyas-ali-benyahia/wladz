# WLADZ — instructions for every coding agent

Before any action in this repository, you MUST:

1. Read and follow `wladz/WLADZ_TEAM_PROMPT.md` (the team's common rules — source of truth).
2. Read `wladz/CRITICAL_CHANGES.md`, both locally and on `origin/main` (`git show origin/main:wladz/CRITICAL_CHANGES.md`), and tell the developer about every entry they have not acknowledged yet (see §2 and §12 of the rules).
3. Read `wladz/AGENTS.md` before writing Next.js code (this project uses Next.js 16).

The Next.js application (npm root) is the `wladz/` folder.
